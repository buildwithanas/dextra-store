Put your product photos in this folder (public/images/).

File names must match each product's "Photo file name" in the admin
(for example: adire-fabric.jpg, tote-bag.jpg).

Tips:
- Use the admin's "Choose photo" button: it resizes the photo and gives you
  a download with the right name. Save it here.
- Square or 4:3 photos under 200 KB load fastest on phones.
- Products without a matching photo show a coloured tile instead.
